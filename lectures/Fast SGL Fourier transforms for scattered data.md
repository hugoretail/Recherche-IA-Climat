# Fast SGL Fourier transforms for scattered data

## Sources

Référence : https://arxiv.org/pdf/1809.10786

Consulté dernièrement le : 7 sept. 2026

## J'en retiens surtout ça

Ce papier propose des fonctions optimisées pour remplacer l'approche classique de SGL (Spherical Gaussian Lattice), avec une évaluation méthodique des performances.

SGL permet de modéliser des données dans un espace polynomial trigonométrique 3D, ce qui est particulièrement utile pour des applications nécessitant une représentation complexe de données spatiales ou environnementales.
