# Recherche-IA-Climat
IA For Sustainability

## Mon Objectif

Il arrive souvent que l'on critique la météo pour ses erreurs de prédictions : on nous annonce des éclaircies dans l'après-midi alors qu'il pleut des cordes. Evidemment, les erreurs dans ce domaine sont possibles car elles se basent sur des probabilités. En revanche, avec le changement climatique qui ne cesse de s'aggraver et le climat qui subit une évolution brutale, j'ai commencé à me poser des questions.
- "Les données historiques météo deviennent-elles obsolètes avec le réchauffement climatique ?"
- "Comment adapter les modèles de ML pour des conditions climatiques en évolution rapide ?"

Dans de répo, vous trouvez mes recherches liées à ce sujet dont :
- Revues de littérature (papers).
- Analyse de jeux de données météo.
- Expérimentation avec des modèles de ML.
- Rédaction du résumé de recherche.
